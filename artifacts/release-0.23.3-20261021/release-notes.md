# Mission Leben Zentral 0.23.3

- Ankündigungen bleiben unter der Glocke 14 Tage ab Veröffentlichung lesbar – auch wenn sie abgelaufen oder in Nextcloud gelöscht wurden.
- „Gelesen“ blendet einen Hinweis nur auf der Startseite aus. Unter der Glocke bleibt er erreichbar.
- Abgelaufene und gelöschte Hinweise sind als „Archiviert“ gekennzeichnet.

Die aktuelle Zugriffsberechtigung wird weiterhin geprüft. Bereits vor Aktivierung der Historie gelöschte Hinweise können nicht rückwirkend wiederhergestellt werden.

Die bestehende Registrierung bleibt erhalten. Android kann bei der Installation wie bisher einen Sicherheitsscan verlangen.
