Mission Leben Zentral 0.23.1

- Persönliche Web-Anmeldungen werden ausdrücklich gespeichert. Das verbessert den Erhalt vorhandener Sitzungen beim App-Neustart, insbesondere für Zimbra, Talk und IT Hilfe.
- Am Kennwortschritt steht klar, dass das normale Kennwort und nicht der TOTP-Code gefragt ist. Codefelder für die zusätzliche Bestätigung bleiben unverändert.
- Fehler des Anmeldedienstes werden von einem bewussten Abbruch getrennt. Eine abgewiesene Anmeldung wird nicht mehr pauschal als „Anmeldung wurde abgebrochen“ angezeigt.
- Für die Fehlersuche stehen ausschließlich Statusangaben bereit, ohne Cookie-Inhalte, Kennwörter oder Tokens.

Geräteregistrierung, Biometrieschutz, zusätzliche Anmeldebestätigungen, 90-Tage-Grenze und Abmeldung auf gemeinsamen Tablets bleiben erhalten. Es werden keine neuen Android-Berechtigungen benötigt. Bei einer normalen Aktualisierung bleiben Registrierung und App-Daten erhalten; keine Neuinstallation nötig.

Updates kommen weiterhin über GitHub mit dem normalen Android-Installationsdialog. Ein angeforderter Sicherheitsscan bleibt möglich.
