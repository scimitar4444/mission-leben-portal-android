# Mission Leben Zentral 0.24.0

- **Sprachnachrichten in Talk:** Im Chat das Mikrofon antippen und sprechen. Der Haken beendet und sendet die Nachricht; X verwirft sie.
- **Mikrofon einfach freigeben:** Der Einrichtungsassistent zeigt einmalig den neuen Schritt für Sprachnachrichten. Später findest du die Freigabe unter **Einstellungen → Talk**. Ohne Freigabe funktionieren Textnachrichten weiterhin.

Die Talk-Einstellungen erscheinen nur, wenn Talk für dich verfügbar ist.
Beim Verlassen wird eine laufende Aufnahme abgebrochen. Die Kamera bleibt im Talk-Container gesperrt.

Das Update behält die bestehende Geräte-Registrierung und Anmeldung bei.
Wie gewohnt kann Android vor der Installation einen Sicherheits-Scan verlangen.
