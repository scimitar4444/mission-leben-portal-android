# Mission Leben Zentral – Android-Downloads

Dieser öffentliche Bereich stellt ausschließlich die fertigen, signierten
Android-Installationsdateien, Update-Prüfsummen und Versionshinweise bereit.
Der Quellcode wird separat in einem privaten Repository verwaltet.

## Installieren

Die einfache Installationsanleitung findest du im
[Mission-Leben-Geräteportal](https://geraete.mission-leben.de/install).

- [Aktuelle Android-App herunterladen](https://github.com/scimitar4444/mission-leben-portal-android/releases/latest/download/mission-leben-zentral.apk)
- [Aktuelle Version und Änderungen](https://github.com/scimitar4444/mission-leben-portal-android/releases/latest)
- [Alle veröffentlichten Versionen](https://github.com/scimitar4444/mission-leben-portal-android/releases)

Android beziehungsweise Google Play Protect kann vor der Installation eine
Sicherheitsprüfung verlangen. Beachte die Hinweise in der Installationsanleitung.

## Bestehende Installationen

Die bisherigen Download- und Update-Adressen bleiben unverändert. Eine
Neuinstallation oder erneute Geräteregistrierung ist wegen der Trennung von
Quellcode und Downloads nicht erforderlich.

Die App prüft vor der Installation Paketname, Version, Dateigröße, SHA-256 und
das Signaturzertifikat. Die Datei `update.json` ist für die automatische
Updateprüfung bestimmt.

Die von GitHub automatisch angebotenen „Source code“-Archive enthalten hier
nur diese Downloadbeschreibung, nicht den Anwendungsquellcode.
