Mission Leben Zentral

Wählen Sie Ihr Android-Gerät aus. Wir führen Sie sicher durch die Installation.

1

Gerät auswählen

Bei Samsung ist vor der Installation ein zusätzlicher Sicherheitsschritt notwendig.

Installation auf Android

  1. Tippen Sie auf App herunterladen.
  2. Falls Android nachfragt, öffnen Sie die Einstellungen und erlauben Sie für Ihren Browser „Apps aus dieser Quelle zulassen“.
  3. Kehren Sie zurück und bestätigen Sie Installieren.
App herunterladen

Installieren Sie auf diesem Weg ausschließlich Mission Leben Zentral und die von der App angebotenen Updates.

Installation auf Samsung Android

  1. Öffnen Sie Einstellungen → Sicherheit und Datenschutz → Automatische Sperre und schalten Sie diese aus. Gemeint ist nicht die Bildschirmsperre.
  2. Wenn Samsung anbietet, die Automatische Sperre nach 30 Minuten wieder einzuschalten, lehnen Sie dies ab. Die Sperre muss für App-Updates ausgeschaltet bleiben.
  3. Tippen Sie anschließend auf App herunterladen.
  4. Falls Samsung nachfragt, erlauben Sie unter Weitere Sicherheitseinstellungen → Unbekannte Apps installieren die Installation für Samsung Internet oder Chrome.
  5. Kehren Sie zurück und bestätigen Sie Installieren.
App herunterladen

Installieren Sie auf diesem Weg ausschließlich Mission Leben Zentral und die von der App angebotenen Updates.
